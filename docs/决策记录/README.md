# 决策记录(ADR)

架构 v2 §0 / §11.1 列出的「第 1 周前两天必须议定的四件事」。每份记录的状态流转:**提议 → 已采纳 / 已否决**。
采纳后不得静默修改;要改就新开一份 ADR 并在旧的顶部写「被 ADR-00x 取代」。

| 编号 | 主题 | 状态 | 影响的任务 |
|---|---|---|---|
| [ADR-001](ADR-001-告警双轨.md) | 告警双轨:哪些进 Device Profile,哪些留规则链 | 提议 | T1.3(profile-alarms)、T2.5、T4.1 |
| [ADR-002](ADR-002-实体按名存按id发.md) | 实体在项目文件中按名存、发布时解析为 id | 提议 | T3.4、T3.7 |
| [ADR-003](ADR-003-calc前缀与级联例外.md) | `calc_` 前缀与多级归档 / 分层汇聚的级联例外 | 提议 | T1.3、T3.4 |
| [ADR-004](ADR-004-kz报表归宿.md) | kz 归档报表在契约中的归宿 | 提议 | T0.2(是否加 `mode: 'ext'`)、T3.1、T3.8 |

模板:

```
# ADR-00x 标题
状态:提议 | 已采纳(YYYY-MM-DD,签字) | 已否决
## 背景
## 决定
## 备选与放弃理由
## 对代码的直接影响
## 签字
```
