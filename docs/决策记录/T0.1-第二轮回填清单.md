# 第二部分 · 庄艳芹(tbClient 包)

**4.1 关于「值转数字」(第一轮 C4)**
你写「无法做到,订阅时是数值变动就会返回,字段会有缺失」——这是说 WebSocket **只推变化的量**,我们知道,而且格式就是按增量设计的,组件只更新收到的量。我们要的其实只有两件小事:
① TB 推来的 `"78.5"`(字符串)转成 `78.5`(数字);
② 主动查最新值时,不存在的量返回 `null` 而不是报错。
