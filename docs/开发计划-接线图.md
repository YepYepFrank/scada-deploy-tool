## 1. 目标与范围

**一句话**:工程人员在部署工具第 4 步里,从 TB 设备树拖设备画出用户侧一次接线图、点选绑测点,发布后在同事前端 / 独立薄壳的页面槽位里带实时数据显示。

范围内(一期):

- 图元库(国标画法,约 22 个)、母线、正交连线、测点数值标签、开关分合着色、**拓扑带电着色**(从电源点沿合位开关传播,失电段变灰)、数据过期变灰、告警闪烁、点击节点抛事件。
- 编辑器:拖放、连线、对齐线、撤销重做、缩放 / 小地图、从 TB 设备树拖入设备自动配图元与默认测点、**复制间隔 ×N 并按设备名规律改绑**、底图描摹、未绑定 / 缺测点清单、实时预览。
- 发布:随页面配置一起发布,沿用现有「按名存、按 id 发」(ADR-002)与客户可见性。

范围外(二期 backlog,§8):遥控分合闸、潮流动画、向导式生成初稿、DWG 自动转换、自定义图元导入。

规模假设:单图 ≤ 300 节点、≤ 400 个测点绑定。

## 2. 关键设计决定(写进 ADR-005,T5.0 产出)

| # | 决定 | 依据(已核对代码) |
|---|---|---|
| D1 | **图存在 `sld` 组件的 `props.doc` 里,随 PageConfig 走**;不新建资产类型 | `WidgetConfig.props` 是自由对象,契约 JSON Schema 不用改;发布、客户可见性、漂移检测零改动。页面经 REST 读写(`StandaloneApp.vue:271`,只读 `pageConfig` 一个键) |
| D2 | **测点绑定放在 `WidgetConfig.bindings`,用动态槽位名** `pt.<pointId>`;`doc` 里只存几何与对 `pointId` 的引用。`pointId` / `nodeId` 字符集限定 `[A-Za-z0-9_-]` | `page-config.schema.json` 对 bindings 的 key 无 pattern 限制;解析器不看注册表、未知槽位照样订阅(`binding-resolver.ts:95`);编译器 `eachBinding()` 遍历全部槽位 → 按名解析 id、key 存在性检查自动覆盖 |
| D3 | **告警只用一个静态槽位 `alarms`**(绑站点资产,依赖告警上卷),组件内按告警 originator 匹配到节点。**不做**每节点一条 `al.<nodeId>` | `legacy-adapter.ts:192-225` 每条告警订阅 = 一个 10 s REST 轮询,300 节点 ≈ 30 次请求 / 秒 |
| D4 | **`doc` 里的实体只存 `{ type, name }`,不存 id**;运行时节点的 id 取自它名下测点绑定的 `entity` | `publish-page.ts:85-98` 的 `collectEntityRefs` 只看 bindings / actions,不看 props;`doc` 里放 id 会在换环境后失效,违反 ADR-002 |
| D5 | 注册表类型加两个**可选**扩展:`WidgetDefinition.dynamicSlots?: { prefix, valueType, modes }[]`;`PropSchema` 加 `{ type: 'object', format: 'sld-doc' }`(属性面板画成「编辑接线图」按钮) | 注册表类型不进 JSON Schema,CI 的 schema 同步不受影响。注:props 校验只在部署工具(`editor/validate.ts:200`),渲染器本身不校验 props |
| D6 | 渲染器运行时三处小扩展(都在 T5.0 串行做):① 动态槽位的值带时间戳 `{ v, ts }`(过期变灰用**数据时间戳**,不用到达时间);② `<ScadaPage>` / `<ScadaWidget>` / `WidgetExpand` 增加通用 `widget-event` 透传(`node-click` 走它)——**宿主可见的 API 新增,要告知庄**;③ 设计态给动态槽位出占位值(`sampleData(cfg)` 带参) | `binding-resolver.ts:132` 目前丢弃时间戳;`ScadaPage.vue:20-27` emits 是封闭清单;`widget-runtime.ts:41-51` 设计态只按固定槽位名给值 |
| D7 | 运行时 `sld` 组件**纯 Vue + SVG,零新依赖**;编辑器用 **AntV X6 3.x**(MIT,3.1.8 于 2026-08 发版),只进 `apps/deploy-tool` | 同事宿主只升渲染器版本,包体不涨 |
| D8 | **图元定义一份、两处用**:`packages/renderer/src/sld/symbols/` 每图元一个文件;`<SldSymbol>` 组件放 `src/sld/`,经包入口 `index.ts` 导出,运行时与 X6 Vue 节点共用 → 所见即所得 | `package.json` exports 只有 `.` 与 `./schema`,深路径引用走不通,必须从入口导出 |
| D9 | 图的纯逻辑集中在 `packages/renderer/src/sld/model/`,无 Vue、无 X6;`doc`↔`bindings` 一致性检查放**部署工具** `editor/validate.ts`,不进编译器 | 编译器刻意零依赖、不依赖渲染器(`compiler/src/page/types.ts:2`),放进去只能手抄一份 SldDoc,易漂移 |
| D10 | 底图(`background`)**不发布**:只存项目文件,发布前剥掉 | data URL 会把页面撑到 MB 级;发布器每次还把最近 10 版完整配置写进 `pageConfigHistory`(`publish-page.ts:19`) |

`SldDoc` v1 草案(T5.0 冻结):

```ts
interface SldDoc {
  v: 1
  canvas: { w: number; h: number; grid: number }
  background?: { src: string; opacity: number } // 仅项目文件,不发布
  nodes: SldNode[] // { id, symbol, x, y, rot: 0|90|180|270, flip?, name?, entity?: { type, name }, state?: { pt, map } }
  buses: SldBus[] // { id, x1, y1, x2, y2, name?, kv? }
  wires: SldWire[] // { id, from: End, to: End, vertices?: [x,y][] };End = { node, port } | { bus, t }
  labels: SldLabel[] // { id, x, y, attach?, kind: 'text'|'value', text?, pt?, format?: { digits, unit, scale } }
}
```

## 5. 多 subagent + git worktree 的编排规则

1. **一个任务 = 一个 subagent = 一个 worktree = 一条短分支** `feat/sld-t5-n`,从当时的 `main` 拉出,寿命 ≤ 2 天;主会话(编排者)是唯一能合入 `main` 的角色,保持主干开发。
2. **写入路径独占**(§4 表格)。需要改别人路径或 T5.0 冻结的只读文件时,subagent 停下来在交付说明里提出,由主会话串行改完再让各分支 rebase。
3. **subagent 没有任何凭据**:worktree 里没有 `.env.local`(git 已排除),不 SSH、不连 TB、不发布;只用 mock 数据与单测。mock 里不写 `password: '…'` 这类字面量(预提交钩子会拦)。凡是要连 CT110 的验证都由主会话做。
4. **依赖只在 T5.0 装一次**;worktree 里 `pnpm install --frozen-lockfile`,谁也不改 `pnpm-lock.yaml`。
5. **合入流程**(主会话逐条串行):rebase 到最新 `main` → 本地四项检查 → push 分支、开 PR → **PR 上 CI 两条绿** → 我读 diff 评审(UI 任务再起 dev server 用浏览器实看;subagent 没有浏览器,happy-dom 也没有 SVG 几何 API,交互只能在这一步验)→ fast-forward 合入 → 删分支。合入顺序:T5.1 → T5.2 → T5.4 → T5.3 → T5.5。
6. 提交信息照旧:Conventional Commits、scope 取 `renderer|tb-client|compiler|deploy-tool|docs|adr`、`Refs: T5.n`。
7. 每个 subagent 的任务书固定五段:目标 / 可写路径 / 只读依赖 / 完成标准(含要跑的命令)/ 交付说明格式(改了什么、没做什么、遗留问题)。不合格的产出退回重做,不由主会话手修,保持任务书可复用。
