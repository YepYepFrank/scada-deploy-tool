## 2. 接一张卡(就这几行)

```vue
<script setup>
import { ScadaWidget, pickWidget, validatePageConfig } from '@grid/scada-renderer'
// 读法和整页一样:GET /api/plugins/telemetry/ASSET/{pageId}/values/attributes/SERVER_SCOPE → pageConfig
const page = validatePageConfig(JSON.parse(raw.pageConfig)).value
const card = pickWidget(page, widgetId)     // 找不到返回 undefined,不抛错
</script>
<template>
  <div class="my-cell"><ScadaWidget v-if="card" :config="card" /></div>   <!-- 尺寸由你的容器定 -->
</template>
```

- `ScadaWidget` props:`config`(必填)、`dataSource?`(缺省用 provide 注入的)、`theme?`(默认 `default`)、`design?`。事件:`invalid`(类型未知 / 绑定形状错,卡片自己显示错误态)、`bindError(widgetId, slot, message)`。
- 卡片 `width/height: 100%`,你给多大容器就多大;不做整页缩放;图表随容器自动 resize。
- 主题令牌 `--sr-*` 在卡片根节点 `.sr-page.sr-widget-standalone` 上生效,想换色在祖先节点覆盖。
- 一页放 N 张卡 = N 份独立订阅,各自退订。

**引用怎么来**:工程人员在工具里选中一张卡,右栏「引用(给前端)」点「复制引用」,给你的是

```json
{ "pageId": "<ScadaPage 资产 id>", "widgetId": "w_xxxxxxxx" }
```

要对照全站,我们跑 `tbsite pages --site <站点> --widgets --json` 给你一份清单。

**组件 id 规则**:创建时生成一次(形如 `w_3k9f2a1c`),改属性 / 绑定 / 换模板都不变;**槽位里的组件换成别的类型 = 另一张卡 = 新 id**。线上老页面里 `w-<槽位>` / `<类型>-<槽位>` 形式的 id 同样有效,不会被改。

## 3. 卡片库

每个站点多一张 ScadaPage 资产,名 `<站点>-卡片库`,模板 `cards`(24 格),资产 `additionalInfo.kind === 'cards'`。

- 读它和读普通页面一模一样(同一个属性 `pageConfig`)。
- 你列站点页面时**按 `additionalInfo.kind` 区分**:`'cards'` 是卡片库,没有 kind 的是大屏页;页面菜单如果列页面,跳过 `'cards'`。
- 工程人员可以直接在卡片库配卡,也可以把页面里配好的卡「存为可复用卡片」进去;两边是复制关系、各有各的 id。

## 5. 首次接入请验这 6 条,结果回我

1. 曲线 / 双轴 / 仪表盘放进你的 rem 容器,窗口缩放时图表跟着 resize、不裁切;
2. 数字卡在最小尺寸(建议不低于 160 × 90 px 等效)下文字不溢出;
3. 字体:组件里是 px + 令牌,不随你的 `html { font-size }` 变——看效果,要跟 rem 走我们再把字号令牌化;
4. 同一页放两张卡订同一个测点(如两个 `kpi-load`),各自更新、关掉一张另一张不受影响;
5. 页面在工具里重新发布后,你的页面刷新即拿到新配置(一期不推送);
6. 客户账号(`xrs-viewer`)打开:卡片绑定的实体不在该客户下时显示「不可用」,与整页一致。

有问题带上 `build-info.json` 里的 commit 和出问题的 `{ pageId, widgetId }`。
