# 渲染器 0.10.0 · 交付说明(给庄艳芹)· 2026-09-22

**这版你什么都不用改。** 全部变化都在 `sld`(一次接线图)组件内部,`<ScadaPage>` / `<ScadaWidget>` 的 props、事件、取数一律照旧,
页面配置契约 `schemaVersion` 仍为 1,`SldDoc` 的 `v` 也仍为 1(新增字段全是可选的,旧图不用迁移)。

换包:**0.9.0 → 0.10.0**。0.9.0 的绑定上下文(`bindingContext`)与 tb-client 0.0.3 的绝对时间区间**仍然是你要做的那一件事**,
见 `给同事的-渲染器0.9.0交付-2026-09-21.md` §2;这一版没有再给你加活。

## 2. 这版改了什么(现场走查一次接线图提的六条,五条在渲染器)

都是「工程人员在部署工具里能配、页面上就照着画」,你这边只是升个包:

| 现场反馈 | 渲染器里加了什么 |
|---|---|
| 电流互感器等图元颜色无法修改 | `SldNode.color`。**失电时颜色仍在、只是变暗**(器件常常不在带电回路里,按失电抹成灰等于不让改);母线的老规矩不变——失电变灰 |
| 设备框只能等比放大,改不了长宽比 | `SldNode.size = { w, h }` + 图元定义的 `freeBody(w, h)`(目前只有 `device-box`)。**按实际宽高重画,不是拉伸**,所以线宽不会被拉扁;端口仍在四边中点 |
| 设备框 / 分组框边框颜色、粗细改不了 | `SldFrame.color` / `width` / `solid` |
| 数据没有对齐 | 数值标签新增 `colW`:前缀左对齐、数字**右对齐**到 `x + colW`、单位跟其后。一组标签设同一个值,数字就排成一列 |
| 开关图元没有显示闭合 | `SldStateRef.fallback`:状态测点没数据 / 过期 / 值对不上时按它画(`'closed'` / `'open'`),缺省仍是虚线的 unknown。**有数据时永远以数据为准** |
| 右侧功能区不能拖宽 | 部署工具的事,与你无关 |

**对你可能有影响的一处**:`SldStateRef.fallback` 配成 `closed` 的开关,在没有数据时也会**参与带电计算**
(按合闸传电),所以页面上带电着色的范围可能比 0.9.0 大。这是现场要的效果——以前因为「不确定」,
一个没有位置信号的开关能把整段线路卡成灰的。

## 3. 内部 API 变动(只有你直接用 `@grid/scada-renderer/sld` 的底层函数时才要看)

正常接 `<ScadaPage>` / `<ScadaWidget>` 的话下面这些都碰不到:

- 新增:`isFreeSizeSymbol` / `freeSizeStep` / `snapFreeSize` / `isValidFreeSize` / `nodeScaleXY` / `nodeLocalSize` / `nodeBoxSize` / `designSwitchState`。
- 签名**向后兼容地**加了可选参数:`symbolTransform(def, rot, flip, kx?, ky?, scaleBody?)`、`symbolPoint(def, rot, flip, x, y, kx?, ky?)`;
  `<SldSymbol>` / `<SldSymbolBox>` 多了 `size` prop。不传全部按原样。
- `validateSldDoc` 多一个 issue code:`bad-size`。

## 4. 怎么验

- 旧页面 / 旧卡片库在 0.10.0 下与 0.9.0 一致(不配新字段就什么都没变)。
- 要看效果:渲染器仓库 `pnpm -F @grid/scada-renderer dev` → http://localhost:5180 选「三栏监控屏」,
  里面的接线图样例已经各放了一个:橙色实线边框的「保护柜」、240×100 的设备框、框里三行对齐的数值、
  两台「没数据按合闸画」的低压出线开关。
