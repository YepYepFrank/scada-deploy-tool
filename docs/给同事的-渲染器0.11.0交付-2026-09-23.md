# 渲染器 0.11.0 · 交付说明(给庄艳芹)· 2026-09-23

**你的接入代码不用改**,但这版有一处**看得见的变化**:接线图里的开关缺省改成了「状态色」——
合闸红色实心、分闸绿色实心、灰色 = 通信异常。升级后页面上的开关会变样,这是现场要的效果。

换包:**0.10.0 → 0.11.0**。你要做的仍然只有 0.9.0 那一件事(tbClient 的 `getHistory` 收 `{ from, to }`),
见 `01-0.9.0交付说明`;这版没有再给你加活。

## 2. 这版改了什么(内测第二轮,都在 `sld` 组件内部)

| 内测反馈 | 渲染器里的变化 |
|---|---|
| 开关合闸 / 分闸显示得一样,应该红色实心合、绿色实心分、灰色通信异常 | 新属性 `switchStyle`,**缺省 `'state'`**:断路器、手车、负荷开关、简化开关画实心方块;隔离刀、接地刀保留刀闸形状、动触头上色。状态色块不跟着失电变暗 |
| 同上(根因) | **开关位置不再判过期**。开关只在变位时上报,一周没变是常态;以前超过 `staleSeconds`(缺省 600 秒)就画成虚线,合、分看起来一样,下游母线也跟着变「不确定」。现在「通信异常」= 设备在线灯明确离线,或测点从没收到过值。`staleSeconds` 只管数值变灰 |
| 开关能否像母线一样直接附着 | 图元端口正好压在母线上就算连通,带电色传得过去 |
| 设备框线宽 / 虚线 | `SldNode.lineWidth` / `dashed`(只对设备框) |

## 3. 可能和你有关的两点

- **想要回原来的样子**:组件属性 `switchStyle: 'classic'`(工程人员在部署工具里改「开关画法」就行,页面配置里带着;你不用写代码)。
- **改颜色**:在 `.sr-page` 或任意祖先上覆盖 `--sr-sld-sw-closed`(缺省 `#ff3b3b`)/ `--sr-sld-sw-open`(`#22c55e`)/
  `--sr-sld-sw-unknown`(`#8a94a6`)。10 kV 的电压等级色也是红色,合闸红块压在 10 kV 母线上对比弱一些,需要的话一起调。

内部 API 只有向后兼容的新增:`<SldSymbol>` / `<SldSymbolBox>` 多了 `switchStyle`(缺省仍是 `classic`)、`lineWidth`、`dashed`;
连通图的边多了 `kind: 'attach'`;导出 `onBus()`。

## 4. 怎么验

- 旧页面在 0.11.0 下:除了开关变成红绿方块,其余与 0.10.0 一致。
- 渲染器仓库 `pnpm -F @grid/scada-renderer dev` → http://localhost:5180 选「三栏监控屏」,接线图样例里能同时看到
  红色(合)、绿色(母联分)、灰色(2# 进线通信异常)三种开关。
