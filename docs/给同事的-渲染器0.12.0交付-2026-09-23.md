# 渲染器 0.12.0 · 交付说明(给庄艳芹)· 2026-09-23

**你的接入代码不用改**。这版和 0.11.0 同一天出,取代 0.11.0 包(0.11.0 没装的话直接装这个)。
有两处**看得见的变化**,都在接线图组件里,都是现场要的效果:

1. **开关**(0.11.0 起):合闸红色实心、分闸绿色实心、灰色 = 通信异常。详见 `01-0.11.0交付说明`。
2. **数值**(0.12.0 新):遥测数值画成「前缀 + 黑底数码管框 + 单位」,像柜面上的数字表头,小数点对成一列。

你要做的仍然只有 0.9.0 那一件事(tbClient 的 `getHistory` 收 `{ from, to }`),见 `02-0.9.0交付说明`;这版没有再给你加活。

## 2. 这版改了什么(内测第二轮第 8 条,都在 `sld` 组件内部)

| 内测反馈 | 渲染器里的变化 |
|---|---|
| 遥测数据最好是小数点在一个纵轴上,看起来整齐;样子参考现有组态里的数字仪表 | 新属性 `valueStyle`,**缺省 `'meter'`**:数值标签画成黑底框 + 七段数码管数字,**右对齐**、每位等宽,小数点不占位——位数相同的数值小数点落在同一条竖线上。数码管是自己画的 SVG path,**不依赖字体包** |
| 同上 | 上下叠在一起的一组(同一个 x、一行挨一行)**自动对成一列**,前缀长短不一(P / SOC / 状态)也对齐 |

## 3. 可能和你有关的几点

- **想要回原来的样子**:组件属性 `valueStyle: 'plain'`(工程人员在部署工具里把「数值样式」改成「纯文字」就行,页面配置里带着;你不用写代码)。
- **改颜色**:在 `.sr-page` 或任意祖先上覆盖 `--sr-sld-meter-bg`(框底,缺省 `#01040b`)/ `--sr-sld-meter-line`(框线)/
  `--sr-sld-meter-ink`(数字,缺省 `#f2f8ff`)。前缀和单位仍用标签色(相色黄 / 绿 / 红)。
- **读数在哪**:数码管是图形,读不出文字。每个数码框整组带 `aria-label="Uab 388.7 V"` 和 `data-value="388.7"`,
  你那边要做自动化测试或取值,用这两个属性。
- **宽度**:数码框比纯文字宽一点(一个标签约宽 10px)。排得很密的图可能挤,由工程人员在编辑器里挪开或改回纯文字。

内部 API 只有向后兼容的新增:`SldLabel`(数值)多了 `look` / `cells`;导出 `meterLayout` 等几何函数(部署工具用)。

## 4. 怎么验

- 旧页面在 0.12.0 下:除了开关变红绿方块、数值变数码框,其余与 0.10.0 一致。
- 渲染器仓库 `pnpm -F @grid/scada-renderer dev` → http://localhost:5180 选「三栏监控屏」,接线图样例里
  「保护」一组 `400.0 / 125.6 / 32.1` 的小数点在一条竖线上;储能那一组 `P / SOC / 状态` 的框对成一列,「停止」写在框里。
