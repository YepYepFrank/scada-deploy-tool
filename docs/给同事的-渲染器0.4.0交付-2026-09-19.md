## 2. 0.3.2:组件放大(你不做任何事也会生效)

`<ScadaPage>` / `<ScadaWidget>` 里每个组件右上角多一个「⤢ 放大」按钮,点开铺满视口再渲染一份(共用同一份数据,不新建订阅),✕ / Esc 关闭。

- 不想要:传 `:expandable="false"`。
- 放大层是 `position: fixed; z-index: 1000`,你有更高层级的弹窗 / 抽屉要留意。
- 事件 `expand(widgetId | null)`。

## 3. 0.4.0:一次接线图组件 `sld` 与 `widget-event`

**接线图不需要你写接入代码**:工程人员在部署工具里画好、绑好测点并发布后,它就是页面里一个 `type: 'sld'` 的组件,`<ScadaPage>` 整页、`<ScadaWidget>` 单卡都会自动画出来——开关分合、带电 / 失电着色(按电压等级)、测点实时数值、数据过期变灰、告警闪烁、滚轮缩放 / 拖动平移 / 双击复位。纯 SVG,**没有给你的包体加任何新依赖**。

**你可能想接的一个事件**:点图上的设备会抛 `widget-event`:

```vue
<ScadaPage :config="page" @widget-event="onWidgetEvent" />
```

```ts
function onWidgetEvent(e: { widgetId: string; type: string; name: string; detail?: unknown }) {
  if (e.type === 'sld' && e.name === 'node-click') {
    const d = e.detail as {
      nodeId: string
      name?: string
      entity?: { type: 'DEVICE' | 'ASSET'; name: string; id?: string }
    }
    // 例:弹这台设备的详情 / 跳到它的页面。entity.id 是发布时解析出的 TB 实体 id;
    // 极少数情况下(页面没发布过、设备在平台上被删了)没有 id,退回按 entity.name 查。
  }
}
```

不监听就什么都不会发生。目前只有接线图发这个事件,其余 10 个组件不发。

## 4. 请你确认一件事:WS 订阅的发送方式

一张接线图有 300–400 个测点。TB 对 WebSocket 单条消息有 32 KB 上限,超了直接断开(我们在新后端实测:一条消息装 300 个订阅就被断)。我们自己的 `LegacyDataSource`(tb-client 0.0.2)已经改成**同一设备的多个测点合成一条订阅 + 按 24 KB 分片发送**,实测 400 个测点合成一条 9.3 KB 的消息。

**你那边正式的 TbClient** 如果也是「一批订阅合成一条消息」发给 TB,请按 `给同事的-WS订阅单条消息上限-2026-09-18.md` 的两条建议处理;如果是一个订阅一条消息,就不受影响。
