## 2. 0.5.0:页面观感(**这版唯一要你看两眼的地方**)

起因是 YY 看配出来的页面「太像 demo,不像最终交付的页面」。所以 0.5.0 全是视觉,**没有任何契约 / props / 事件 / 取数变化**,但升级后**页面会自己变样**,你心里得有数:

1. **`<ScadaPage>` 现在会画自己的背景** —— 深海蓝渐变 + 两团光晕 + 细网格 + 四周暗角;`overview-a` / `monitor-3col` 这种固定设计稿的大屏还会在舞台四角画 L 形角标。整层 `pointer-events: none`,不挡任何点击。
   - **你的应用如果已经有整套背景、或者这层跟你的底色打架:`<ScadaPage :decor="false" />`,观感回到 0.4.0。**
   - 想只调不想关:令牌 `--sr-page-bg`、`--sr-glow-1/2`、`--sr-grid-line`、`--sr-grid-size`、`--sr-vignette`、`--sr-corner`,在 `.sr-page` 或任意祖先上覆盖。
2. **固定设计稿的大屏在容器里居中了**(以前只水平居中,容器比设计稿「高」的时候下面空一条)。
3. **卡片有质感了**:上下渐变底 + 顶边一道发丝高光 + 外投影,卡头多一道向右淡出的蓝色洗底、标题前一根渐变小竖条。令牌 `--sr-panel-top/bot/edge/shadow/hairline`、`--sr-title-wash`。
4. 零碎:数字卡顶部色条向下洇一层微光、数字带弱辉光;状态灯圆点双层光晕;表格斑马行 + 表头渐变;告警横幅用面板同款底;**接线图 `sld` 从「浮在页面上」改成一块有底有边的面板**。

### 可选字体包(建议装上,一行代码)

主题里 `--sr-font-title` / `--sr-font-num` 一直写的是「优设标题黑」和「Barlow SemiBold」,但**包里没带字体**,所以在你那边一路回退成微软雅黑——页面「像 demo」有一半是这个原因。0.5.0 把两款字体转成 woff2 放进包里,单独一个入口:

```ts
import '@grid/scada-renderer/style.css'
import '@grid/scada-renderer/fonts.css' // 加这一行,标题与数字就是大屏该有的字形
```

- **不 import 就一个字节都不加载**,主包体积和 0.4.0 一样。
- 体积:优设标题黑 616 KB + Barlow 49 KB。两款都可商用(优设标题黑免费商用、Barlow 为 OFL)。
- 你们应用已经自己 `@font-face` 过这两款的话,就别引了,避免下两遍。

## 3. 0.3.2:组件放大(你不做任何事也会生效)

`<ScadaPage>` / `<ScadaWidget>` 里每个组件右上角多一个「⤢ 放大」按钮,点开铺满视口再渲染一份(共用同一份数据,不新建订阅),✕ / Esc 关闭。

- 不想要:传 `:expandable="false"`。
- 放大层是 `position: fixed; z-index: 1000`,你有更高层级的弹窗 / 抽屉要留意。
- 事件 `expand(widgetId | null)`。

## 4. 0.4.0:一次接线图组件 `sld` 与 `widget-event`

**接线图不需要你写接入代码**:工程人员在部署工具里画好、绑好测点并发布后,它就是页面里一个 `type: 'sld'` 的组件,`<ScadaPage>` 整页、`<ScadaWidget>` 单卡都会自动画出来——开关分合、带电 / 失电着色(按电压等级)、测点实时数值、数据过期变灰、告警闪烁、滚轮缩放 / 拖动平移 / 双击复位。纯 SVG,**没有给你的包体加任何新依赖**。

**你可能想接的一个事件**:点图上的设备会抛 `widget-event`:

```vue
<ScadaPage :config="page" @widget-event="onWidgetEvent" />
```

```ts
function onWidgetEvent(e: { widgetId: string; type: string; name: string; detail?: unknown }) {
  if (e.type === 'sld' && e.name === 'node-click') {
    const d = e.detail as {
      nodeId: string
      name?: string
      entity?: { type: 'DEVICE' | 'ASSET'; name: string; id?: string }
    }
    // 例:弹这台设备的详情 / 跳到它的页面。entity.id 是发布时解析出的 TB 实体 id;
    // 极少数情况下(页面没发布过、设备在平台上被删了)没有 id,退回按 entity.name 查。
  }
}
```

不监听就什么都不会发生。目前只有接线图发这个事件,其余 10 个组件不发。

## 5. 请你确认一件事:WS 订阅的发送方式

一张接线图有 300–400 个测点。TB 对 WebSocket 单条消息有 32 KB 上限,超了直接断开(我们在新后端实测:一条消息装 300 个订阅就被断)。我们自己的 `LegacyDataSource`(tb-client 0.0.2)已经改成**同一设备的多个测点合成一条订阅 + 按 24 KB 分片发送**,实测 400 个测点合成一条 9.3 KB 的消息。

**你那边正式的 TbClient** 如果也是「一批订阅合成一条消息」发给 TB,请按 `给同事的-WS订阅单条消息上限-2026-09-18.md` 的两条建议处理;如果是一个订阅一条消息,就不受影响。
