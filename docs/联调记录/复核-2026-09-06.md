## 4. 代码审核发现与处理

### 4.1 当日修复(均已提交)

1. **向导第 5 步的两个回调不生效**:`@published` / `@restored` 写成模板内联表达式 `editorRef.x()`,在这个 JS SFC 里不执行——发布后左栏仍显示旧资产名,「恢复为当前」不把那版装回编辑器。改为 script 函数 `onPagePublished / onPageRestored`,实操验证:改名发布后页面块切到新名 v5,恢复 version 3 后编辑器装入 5 组件配置。
2. **「清空」不清沿用的资产名**:从 TB 读回页面后 `pageNameOverride` 一直挂着,清空重做的新页面会原地覆盖刚读回的资产。`resetAll()` 一并清掉。
3. **旧属性名读入编辑器被当多余键**:T3.9 把 `line.style` 改成 `chartStyle` 后,渲染有 `migrateProps` 兜底,但编辑器读入 TB 上的旧配置时校验层报「多余键 style」、发布按钮被禁。渲染器新增 `migrateConfigProps(config)`(整份配置正规化,导出),编辑器所有读入路径(TB 读回 / 导入 / 恢复历史 / 漂移反向导入 / JSON 粘贴)统一走它;渲染器 +1 单测。
4. **compiler `migrate.test` 偶发超时**:要加载渲染器 dist 并编译 ajv,机器忙时超过默认 5 s。`vitest.config` 设 `testTimeout: 20_000`。
5. **过期文档 6 处**:计划 T3.7 复选框、compiler README(`makePublic` 选项、测试文件清单)、`summarizePlan` 的「并公开」文案、联调环境(站点资产在 Public / 无 Relation)、ADR-002 / 004 状态、里程碑清单勾选。

### 4.2 复核过但不改的点(记录)

- `packages/compiler/src/writer/api.ts` 的 `TbApi` 返回 `any`(带 `eslint-disable`):有意为之,TB 响应形状在各步各异;上层用处都做了断言。
- `PublishPanel` 里 `publishPage(config as never, …)`:`PageConfig` 与编译器的 `PagePayload` 结构兼容但类型不互认;可在 T4 把 `PagePayload` 改成从渲染器 schema 引类型,现阶段不动(避免编译器依赖渲染器)。
- 向导「记住登录」把账号密码 base64 存 localStorage(迁入前就有,注释写明内网工具场景):建议 W4 改为只记账号不记密码,列入 T4.4 前的待办。
- 大屏 `?base=` 直连另一域会被浏览器跨域拦截:部署时用同域反代或 TB 侧开 CORS,W4 现场项。
- live 用例的临时站点会在设备上留下 `t25*_*` 遥测 key(CF 删了,历史点还在,7 天 TTL 后清):对功能无影响,KeyPicker 里会看到,记入 live/README。
- 漂移检测按项目文件里全部 `published` 键在当前站点下找资产:项目文件若含别的站点的页面会报「资产已不存在」——单站点项目现阶段没影响,多站点时要按站点分组。
- 安全面:无 `v-html` / `innerHTML`;凭据只在运行时输入(dev 模式 `VITE_*` 预填仅本机);`.env.example` 无真值;CLI 拒绝 `--password`;token 只在内存 / sessionStorage(大屏)。
