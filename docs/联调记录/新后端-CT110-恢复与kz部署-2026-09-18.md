## 4. 注意 / 未做

- **110 的 TB 账号密码是 dump 里的**,不一定与镜像相同;要把它们写进 `dev/.env.local`(`TB_USER / TB_PASSWORD`,以及切换后端用的 `TB_BASE=http://192.168.20.60:8080`)才能用 CLI / live 用例 / 部署工具对它联调。`vite.config.js` 自 09-18 起从 `.env.local` 读 `TB_BASE / KZ_BASE`,不填仍是镜像。
- kz 的 ⑤b(按实体归属过滤)在 110 上同样没有,与镜像一致。
- 110 `thingsboard.conf` **没有 TTL**,但当前写入量极小(见 §1),先不设;若以后把网关模拟器接到它上面,要按附录 B 的做法先设 TTL 再放数据。
- 110 内存 4 GB:TB(常驻约 2.2 GB)+ kz(`-Xmx768m`)+ Redis + PG,`free` 显示可用约 1.8 GB,够用但没有余量,别再往上加服务。
- PVE 面板对 110 没做快照;要「一键回到恢复后的干净态」可以现在打一个。
- 宿主 `/root` 上留着 `ct110-restore.sh` 与 `thingsboard_new_backup.sql.gz`(以及 09-08 的 `tb-api-admin-updated.jar`、`gridops-dist.tgz`),不占多少空间,未删。
